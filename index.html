Developer takeaway

DEFENSE

Hiding a button or changing a URL is not authorization. The server must verify permissions on every request.

✓Derive the authenticated identity from a trusted server-side session or token.
✓Check record ownership or an explicit permission before returning data.
✓Return 403 Forbidden (or a privacy-preserving 404) when access is denied.
✓Test horizontal access (user A → user B) and vertical access (user → admin-only action).
AccessLab is an educational mock-up. Client-side checks are not a substitute for backend authorization.
